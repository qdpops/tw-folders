# tw_folders: companion plugin for the Breeze skin

Read-only mirror of `plugins/tw_folders` from [qdpops/roundcube-skin-breeze](https://github.com/qdpops/roundcube-skin-breeze), published for Composer. Issues and pull requests go to the main repository.

Folder icons and colors, folder rules applied by Roundcube itself (no ManageSieve needed), attachment chips in the message list, and a read-only "From mail" address book. Install it together with the skin:

```bash
composer require qdpops/breeze
```

Roundcube 1.6 and 1.7, GPL-3.0-or-later.
